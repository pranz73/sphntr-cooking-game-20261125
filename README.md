**Warung Senja** — an original dusk-stall cooking game. You run a small Indonesian street-food stall at dusk: customers order from the board, you build their dish from the ingredients on the counter (Nasi Goreng Senja, Mie Ayam Senja, Sate Ayam, Es Teh Manis), and you serve it before their patience runs out. Correct serves build a combo multiplier; wrong dishes and walk-away customers break it. One shift lasts 3 minutes. All art is drawn in code, all sounds are synthesized with WebAudio — plain static files, no dependencies, no network: it plays offline in a desktop browser with keyboard and mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
